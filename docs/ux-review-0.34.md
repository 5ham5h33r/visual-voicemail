# Five-question review: onboarding and motion, version 0.34

1. **Where could users drop off?** The introduction stays optional: Get Started opens the inbox. Show me around is visibly separated by 12 dp, and every optional page supports both swipe and button navigation. Permission requests remain optional.
2. **Which assumptions need checking?** Swipes are not assumed to be discoverable or accessible to everyone; Continue, Back, Skip, page indicators, and the real-control spotlight tour remain. A passing gesture check does not establish first-time-user comprehension.
3. **Which edge cases could fail?** Cancelled/short swipes, vertical drags, first/last boundaries, repeated navigation, and Reduce motion use the shared native pager. Both navigation directions save the current page. The sample interactions retain their state when revisited. Forty-eight onboarding assertions passed; Settings-driven recreation and the existing large-text layout checks remain covered separately.
4. **How does this compare with familiar apps?** The inbox and introduction now share one finger-tracking navigation behavior, with native buttons and scrolling as alternatives. Playback progress follows rendered frames rather than a status timer. This applies the same direct-manipulation principle as familiar native apps without claiming an OEM implementation or measured performance on every device.
5. **What breaks with low context or bad connectivity?** Sample actions and introduction navigation require no carrier or speech-model connection. Setup never depends on gesture use. Existing recordings remain untouched by this change. Forty-four first-use/spacing, 36 inbox-navigation, and 480 adaptive-layout assertions passed on the sample emulator. Human first-use comprehension, broader OEM accessibility, and direct carrier push reliability remain open.

The original 44-second demo pipeline was reviewed separately. A constant-rate export did not solve the original sparse source capture. Token-protected host screenshot streaming replaces the slow guest encoder, records near 60 native frames per second, and preserves text without motion interpolation. Reviewed crops retain complete search controls and transcript cards. Licensed music replaces the synthesized soundtrack, with credit in the end card, metadata, captions, and post copy.

All new validation was emulator-only. The physical phone was not connected. The complete capture helper restored its synthetic inbox and preferences.

The later [32-second launch-film revision](product-launch-brief.md) replaces the device-shaped composition and credited soundtrack with a rectangular generic capture, focused native UI crops, and music that permits use without public attribution. No app behavior changed in that media revision.
