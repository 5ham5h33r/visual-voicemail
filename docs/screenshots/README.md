# Documentation screenshots

These are native app-window captures from version 0.11 on a Samsung Galaxy S24 Ultra. Caller names/numbers, message dates, and the last-update timestamp were hidden in temporary views before capture. The player was prepared from an existing cached recording, muted, and paused. No audio file is included.

System status/navigation icons and other application windows are excluded. Each PNG was visually reviewed and checked for text/EXIF metadata before being added. The six images total about 1 MB. Raw/private captures and temporary capture tools remain in ignored local directories.

The capture helper only changed temporary rendered views and restored appearance/refresh preferences afterward. It did not edit saved caller information, carrier read status, recordings, greetings, forwarding, or the default dialer. The `Caller hidden` and `Date hidden` labels are documentation redactions, not an app setting.

When refreshing this gallery, review every image for personal information and update the version above. Never add an unreviewed raw capture.
