I wanted a cleaner way to catch up on my Mint Mobile voicemail, so I built Voice Mail for Android.

It uses my existing carrier mailbox while Samsung Phone stays my dialer. I can read a transcript, tap a phrase to hear that part of the recording, and search for a detail later. Whisper transcribes on the phone.

This preview uses fictional callers and sample text on an S24-proportioned emulator. I tested carrier playback separately on my S24 Ultra; the latest work stayed on the emulator. Independent carrier push is still unverified, and transcripts can contain mistakes.

I'd like feedback on the playback and transcript flow.
